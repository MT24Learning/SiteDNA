# SiteDNA

**Read the design DNA of any website.**

SiteDNA is a Chrome extension that pulls the colors, fonts and images out of the page you are on, checks how consistent and readable they are, and turns them into design tokens you can paste into your project.

[Website](https://mt24learning.github.io/SiteDNA/) · [Privacy policy](https://mt24learning.github.io/SiteDNA/privacy.html) · Chrome Web Store: coming soon

## Features

| Free, with no limits | PRO, for one payment |
| --- | --- |
| Every color on the page, most used first, copied in one click | A brand kit report you can save as a PDF and hand to a client |
| The typefaces the site really uses, without generic names or icon fonts | A consistency audit: near-duplicate colors, stray font sizes and text below WCAG AA contrast |
| Images and SVG icons, ready to save one by one | Design tokens as CSS variables, a Tailwind v4 theme or a W3C Design Tokens (2025.10) file |
| No daily quota and no account | Every image on the page saved in one click |

## Privacy at a glance

- The analysis runs inside your browser. Pages you analyze are never sent anywhere.
- No analytics, no tracking, no ads, no account.
- The only thing SiteDNA sends anywhere is your license key, to Polar, when you activate PRO.

Read the full [privacy policy](https://mt24learning.github.io/SiteDNA/privacy.html).
