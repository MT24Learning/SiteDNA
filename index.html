How it works

  1. Open any website

    Click the SiteDNA icon in your toolbar. It reads only the tab in front of you, and only when you click.

  2. Browse what it found

    Colors, fonts and images appear in three tabs. Click a color or a font to copy it.

  3. Export the report

    With PRO, one click opens the full brand kit with the audit and the tokens, ready to print or share.

Inside the PRO report

  1. Color paletteEvery color on the page, ordered by how often it is used.
  2. Typography systemThe typefaces in use, with a preview of each.
  3. Brand assetsLogos, icons and images found on the page.
  4. Design consistency auditColors so close they should be merged, font sizes used once or twice, and text that fails WCAG AA contrast, with the exact ratio.
  5. Design tokensThe cleaned-up palette and type scale as CSS variables, a Tailwind v4 theme or a W3C Design Tokens file.

Questions

Does SiteDNA send the websites I analyze anywhere?

No. Colors, fonts and images are read and processed inside your browser. The only thing SiteDNA sends anywhere is your license key, to Lemon Squeezy, when you activate PRO. The privacy policy has the details.

Do I need an account?

No. The free features work as soon as you install. PRO needs only the license key from your receipt.

How many computers can I use PRO on?

Each license key activates on up to three Chrome installations.

What is WCAG contrast?

WCAG is the web's accessibility standard. Its AA level asks for a contrast ratio of at least 4.5:1 between normal text and its background, and 3:1 for large text. SiteDNA measures every text and background pair it can see and lists the pairs below that line.

Which token formats can I export?

CSS custom properties, a Tailwind CSS v4 @theme block, and a .tokens.json file in the W3C Design Tokens format (2025.10).

Can SiteDNA read every page?

It reads normal web pages. Chrome keeps its own pages, such as the new tab page, settings and the Chrome Web Store, closed to every extension.
